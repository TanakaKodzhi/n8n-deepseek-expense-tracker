# 🤖 Умный трекер расходов в Notion (n8n + DeepSeek + Telegram) #

Автоматизированный пайплайн на базе self-hosted n8n, который принимает неструктурированные текстовые сообщения о тратах из Telegram, извлекает сущности с помощью LLM (DeepSeek) с жесткой типизацией и сохраняет структурированную запись в Notion.

---

## 📌 Ключевые возможности

• **Парсинг естественного языка:** Преобразование свободного текста (например, `Кроссовки "Спортмастер" 2399`) в структурированные финансовые сущности.
• **Автоматическая категоризация (In-Context Learning):** LLM сопоставляет покупку с категориями бюджета (`Кафе и перекусы`, `Еда и продукты`, `Одежда и покупки`, `Спорт и здоровье`).
• **Защита от галлюцинаций:** Использование узла `Structured Output Parser` гарантирует получение строго типизированного JSON без мусорного markdown-текста.
• **Первичная валидация (Узел If):** Фильтрация нерелевантного спама, стикеров и сообщений без сумм до обращения к платному API модели.
• **Быстродействие и низкая себестоимость:** Время фиксации расхода — ~2.66 сек., стоимость 1 000 транзакций — $0.02–$0.04.

---

## 🛠 Стек технологий

• **Оркестратор:** [n8n](https://n8n.io/) (Self-hosted)
• **Интерфейс ввода:** [Telegram Bot API](https://core.telegram.org/bots/api)
• **LLM Engine:** DeepSeek Chat Model (через DeepSeek Platform)
• **Парсер схемы:** LangChain Structured Output Parser
• **Хранилище данных:** [Notion API](https://developers.notion.com/)

## 📐 Архитектура пайплайна

```text
[Telegram Message]
       │
       ▼
 [Узел If: Валидация входного текста]
       ├─ (False) ──► [Send Error Notification] ──► (Telegram Reply с примерами)
       │
       └─ (True)  ──► [AI Agent: DeepSeek Chat] 
                            │ (Structured Output Parser)
                            ▼
                     [Валидный JSON] ──► [Notion API: Create Page]
```

### Схема маппинга данных в Notion

| Входящий текст | Поле JSON (`item`) | Категория (`category`) | Сумма (`amount`) | Свойство Notion |
| :--- | :--- | :--- | :--- | :--- |
| `Кроссовки "Спортмастер" 2399` | Кроссовки | Одежда и покупки | 2399 | `Title` / `Select` / `Number` |
| `Столовая 2010` | Столовая | Кафе и перекусы | 2010 | `Title` / `Select` / `Number` |
| `молоко "Пятерочка" 100` | молоко | Еда и продукты | 100 | `Title` / `Select` / `Number` |
| `Аптека «Миницен» 2349` | Аптека «Миницен» | Спорт и здоровье | 2349 | `Title` / `Select` / `Number` |

## 🚀 Быстрый старт и развертывание

### 1. Предварительные требования
• Развернутый инстанс **n8n** (self-hosted на Docker/VPS или облачный).
• **Telegram Bot Token** (полученный через [@BotFather](https://t.me/BotFather)).
• **API Key** для доступа к DeepSeek (через официальный кабинет или OpenRouter).
• **Интеграция Notion:** внутренняя интеграция с правами на запись и ID целевой базы данных.

### 2. Структура базы данных Notion
В целевой базе данных Notion должны быть созданы следующие свойства:
• `Что купили` — тип **Title**
• `Категория` — тип **Select** (список опций создается автоматически при первой записи)
• `Сумма (RUB)` — тип **Number**
• `Дата` — тип **Date**

### 3. Импорт воркфлоу в n8n
1. Скачайте файл `workflow.json` из корня этого репозитория.
2. В интерфейсе n8n нажмите меню `...` (в правом верхнем углу) -> **Import from File**.
3. В нодах настройте соответствующие учетные записи (Credentials):
   * `Telegram Trigger` и `Send Telegram Message` — ваш Telegram Bot Credentials.
   * `DeepSeek Chat Model` — OpenRouter / DeepSeek API Token.
   * `Notion` — Notion API Token.
4. В ноде `Notion (Create a database page)` укажите `Database ID` вашей финансовой таблицы.
5. Переключите тумблер сценария в положение **Active**.

## ⚙️ Обработка ошибок и краевых случаев

* Если сообщение не содержит числового значения стоимости или отправлен нетекстовый файл, узел `If` перенаправляет поток на отправку шаблона-подсказки с корректными примерами ввода.
* Поле `Дата` фиксируется автоматически через системную переменную `{{ $now }}` в момент прохождения триггера, исключая рассинхронизацию часовых поясов.
